# TSSDN

## 方法简介

**时间–空间–结构动态网络（Temporal-Spatial-Structural Dynamics Network，TSSDN）** 通过联合学习多时相高分辨率影像中土地覆盖要素的时间、空间与结构特征，实现城市土地利用功能变化的精准检测。网络基于邻接单元矩阵（Adjacency Unit Matrix，AUM），将覆盖要素的“对象–对象”级空间拓扑关系压缩为“对象类型–对象类型”间的相互关系，以提升建模效率。

网络分别从相邻时相对和首末时相对中提取短期与长期变化信息，联合表征节点状态和拓扑结构差异，并利用时空图神经单元协同学习时间、空间与结构动态。在此基础上，通过门控残差融合将变化证据自适应注入时空表征，增强真实变化响应并抑制伪变化干扰。
